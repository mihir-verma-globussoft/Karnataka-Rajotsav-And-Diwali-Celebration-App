# Rajyotsava module: notes for agents and developers

Read this before changing anything in `lib/features/rajyotsava/`, together
with the repo's root [AGENTS.md](../../../AGENTS.md) and
[docs/DESIGN_SYSTEM.md](../../../docs/DESIGN_SYSTEM.md).

**Keep this file current.** When you change the module, update the matching
section here in the same commit (what exists, decisions and why, open
items), so the next person or agent starts from the real state. Remove
statements that are no longer true.

## Ownership and workflow

- Owner: Chethan Nayak. This is the first tab ("Rajyotsava", Karnataka
  Rajyotsava, 1 November). Teammates own the other modules (Deepavali,
  Games, Flappy Bird, AR, Team, the app-wide login and gate). Do not edit
  their code from here; tell them instead.
- Commits go straight to `main` (no branches or PRs), one commit per
  logical phase, then push. Fetch and rebase first: teammates push often.
- Before committing, run `./scripts/check.sh` and gate on its **exit code**,
  not on reading the output.
  It passes as of 2026-11-04, and GitHub Actions (`.github/workflows/ci.yml`)
  runs the same script plus `flutter build apk --debug` on every push.
  Keep it green. Arcade-style tokens for the gate, login and Flappy Bird
  live in `lib/core/theme/arcade_tokens.dart`.
- Must work on Android and iOS. Every screen must fit 320 x 568 at 2x text.
- Run the app with `--dart-define-from-file=.env` (VS Code: the "Globus
  Habba (Debug)" launch config). Since commit `7c0fecb`, dev builds also
  have the backend settings built in.
- Tests that build `App` directly must override `appConfigProvider` with
  an empty `AppConfig`, as `testApp()` in `test/helpers.dart` does.
  Otherwise the app opens on the Google sign-in, not the tabs.

## Layout

```
rajyotsava_feature.dart    tab + routes; every screen is wrapped in
                           RajyotsavaTheme + EasterEggScope (_screen)
rajyotsava_routes.dart     /rajyotsava/{quiz,learn,discover,nearby,culture,
                           cinema,collection,photo-credits,district/:id,
                           discover/:id}
rajyotsava_providers.dart  all Riverpod providers of the module
domain/   pure Dart: models, quiz deck/session/scores, easter eggs, shake
          detector, nearby, calendar, interfaces for plugins
data/     bundled content, photos, plugins (TTS, location, links, song,
          sensors), shared_preferences stores, Supabase quiz scoreboard
presentation/  screens; widgets/ has shared module widgets
```

Rule: `presentation/` never imports `data/` (the architecture test checks).
Screens go through providers. Never import another feature's internals.

## What the module has

- **Tab:** festive banner (waving flag, toran, countdown), explore tiles,
  history, facts, wishes with Kannada voice. Confetti and fireworks run
  across the whole tab, continuously, only while it is visible and the
  app is in the foreground. They stop with Reduce Motion.
- **Song:** "Huttidare Kannada Nadalli Huttabeku"
  (`assets/audio/huttidare_kannada.mp3`) plays once per visit to the tab,
  only on this tab. A mute button sits top right, and the song pauses while
  the voice-over speaks. On iOS it uses the ambient audio category with
  `focus: gain`; Android mixes with others.
- **Quiz** (`quiz_page.dart`): 63 questions with hidden difficulty.
  `QuizDeck` deals rounds of 10 with 2-4 hard questions, easy first, and
  no repeats until a group is used up. Options are shuffled. Points: 100,
  150 or 200 by difficulty, plus up to 50 for answering within 10 s;
  the best round is 2200.
- **Learn Kannada** with TTS, **Discover Karnataka**, **Near me**
  (location permission, with a choose-a-district fallback, and directions
  in Maps), **Songs & Folk Arts** (YouTube searches), **Kannada Cinema**,
  and **Photo credits**. There are 214 Wikimedia photos in
  `assets/images/{stars,discover,places,eggs}`, generated by
  `tool/rajyotsava_photos/` (see its README).
- **Easter eggs:** 22 collectibles (`data/easter_egg_collectibles.dart`).
  - Found by shaking on any Rajyotsava screen, or by secret taps:
    - the flag, 5 taps
    - the "Vowels" heading in Learn Kannada, 5 taps
    - Dr. Rajkumar's photo in Cinema, 5 taps
    - the quiz results trophy, 3 taps
    - the Near me icon, 5 taps
    - the district icon, 5 taps
    - a long-press on the Songs & Folk Arts title
  - All triggers go through `EasterEggManager`. There are no repeats until
    all are found, then a completion card. Progress is saved with
    shared_preferences (`rajyotsava.easter_eggs.v1`).
  - Reveal: a 3D card (tilt, flip, foil). The collection screen
    ("Karnataka Secrets") shows found cards, locked silhouettes, filters
    and a "Need a hint?" sheet (`karnatakaEggHints`).
  - Legendary pop-out: on Rajkumar, Kuvempu, Basavanna and Kittur
    Chennamma the subject rises out of the card frame. The cut-outs are in
    `assets/images/popouts/`, made with
    `tool/rajyotsava_photos/cutout.swift`. Hampi, Mysuru Dasara and the
    Western Ghats stay flat, because their photos have no clear single
    subject.
- **Haptics:** use `hapticsProvider` (`AppHaptics`, shared by the app),
  never `HapticFeedback` directly.

## Online quiz scores (shared Supabase)

- `data/supabase_quiz_scoreboard.dart` saves rounds to the app's shared
  games backend (see `docs/GAMING_BACKEND.md`) as game slug
  `rajyotsava_quiz`, using the player already signed in to the app.
- It calls `submit_game_result`, `get_my_stats` and `get_leaderboard`
  directly. It does not reuse Flappy Bird's repository, whose offline
  queue is Flappy-specific.
- Each round has a UUID made when it starts, so a resend is counted once.
- Failed sends are queued per player (`rajyotsava.quiz.pending.v1.<uid>`)
  and resent when the quiz opens.
  - Never drop queued rounds because of a server error. The server returns
    the same code (`22023`) for "game not registered" as for a bad round.
  - Rounds are dropped only when older than 29 days. At most 50 are kept.
- **Open:** `supabase/migrations/202611040001_rajyotsava_quiz_game.sql`
  (max 2500 points, 1 hour, 3 ms per point) has to be applied to the
  Supabase project by its owner (the Flappy Bird teammate). Until then,
  rounds wait on the phone.

## Performance decisions (measured on an iPhone, profile mode)

- The ambient motion uses one ticker. Painters repaint from a shared
  `AmbientMotion` listenable without rebuilding widgets. Keep it that way.
- The 3D card is costly if done naively. Keep all of these:
  - The shadow is drawn flat, outside the perspective transform.
  - `Transform(filterQuality: medium)` on the card.
  - `SnapshotWidget` while the card or the reveal moves (live text under a
    changing transform rebuilds the glyph atlas on every frame).
  - The back is reached by turning from -90° to 0°, not by mirroring.
- The result: the reveal averages 2.0 ms of GPU time per frame, with no
  missed frames.
- Re-measure with `integration_test/rajyotsava_perf_test.dart`; the
  instructions are in the file. Use fixed `pump`s on devices, not
  `pumpAndSettle`, because the tab animates continuously.

## Gotchas

- `design_system_test.dart` matches `duration: Duration(` literally.
  Build data durations in a variable first.
- Off-screen list items are not built in tests. Scroll with
  `scrollUntilVisible` on the screen's own `Scrollable` (e.g. a descendant
  of `QuizPage`), not on `find.byType(Scrollable).last`.
- Each quiz question has its own `ListView` key, so it opens at the top.
- Text on the section's bright yellow (`tertiaryContainer`, the flag
  yellow) uses `onTertiaryContainer`, which `RajyotsavaTheme` sets to
  `AppColors.ink`. The generated olive failed 4.5:1 there. Tests check
  the theme's colour pairs and the Near me card.
- Card photos are cropped to 5:7 (`BoxFit.cover`). A photo taller than
  that needs `photoFocusY` on its collectible (Sangolli Rayanna: -1 keeps
  his head). Every other current photo is wider, so only its sides are
  trimmed.
- The iOS bundle ID is `com.globussoft.rajotsavAndDiwaliCelebrationApp`.
  `docs/FLAPPY_BIRD_SETUP.md` still names `com.globus...`; the Google iOS
  OAuth client may need updating if sign-in fails on iPhone.
- `ios/Runner/Info.plist` still has `CFBundleName`
  `rajotsav_and_diwali_celebration_app` (shown in the iOS sign-in sheet).
