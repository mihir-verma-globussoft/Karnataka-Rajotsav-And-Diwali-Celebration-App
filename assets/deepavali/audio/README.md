# Deepavali audio

The Deepavali tab plays whichever of these files exist. A missing file stays silent; with none at all, the mute button is hidden.

| File | Used for |
|---|---|
| music.mp3 | Background song while the Deepavali tab is open (loops, quiet) |
| diya_light.mp3 | A diya is lit (diya game, wishes) |
| gust.mp3 | A gust of wind in the diya game |
| win.mp3 | A win or a high score |
| correct.mp3 | A correct answer (quiz, guessing game) |
| wrong.mp3 | A wrong answer |
| tap.mp3 | A small tap (rangoli, decorate, greeting card) |

Other formats (ogg, m4a, aac, wav) work too, but use mp3 or m4a so iPhone can play them. Keep the audio compressed to keep the app small: effects short, mono, about 96 kbps (under about 50 KB each), and the song 80 to 96 kbps stereo MP3 (about 2 MB). Re-encode from the original, not from an already compressed copy. Only add files the team has the right to distribute in the app, and list each in CREDITS.md. See CREDITS.md for where the current files came from.
